# Yhile

Yhile (yhile.com) is a free collection of browser-based file conversion tools. Everything runs client-side, so files never leave your device. No uploads, no signup, no ads.

Live site: https://yhile.com

## Why

Most online converters upload your files to a server, show ads, and require an account. Yhile does none of that. Processing happens entirely in the browser using FFmpeg WASM.

## Tools

| Tool | Description |
|---|---|
| MP4 to MP3 | Extract audio from video files |
| HEIC Converter | Convert iPhone HEIC photos to JPG or PNG |
| Audio Converter | Convert between audio formats |
| Collage Maker | Combine multiple images into one layout |
| More | 10+ tools total |

## Tech

- FFmpeg WASM for client-side media processing
- No backend file storage
- No dependencies beyond the browser

## Use cases

- Convert iPhone photos to JPG without installing software
- Extract audio from video files
- Convert audio formats without uploading files to a third party
- Make photo collages in the browser

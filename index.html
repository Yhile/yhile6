Frequently asked questions

Are all tools on yhile.com really free?

Yes — every tool is 100% free with no signup, no account, no credit card, and no usage limits. Free forever.

Do my files get uploaded to a server?

No. Every tool runs entirely in your browser using JavaScript and WebAssembly. Your files never leave your device and are never sent to any server — because we don't have one.

Do I need to create an account?

No account, no login, no email, and no registration of any kind is required. Open any tool and start using it immediately.

Do the tools work on mobile phones?

Yes. All tools are designed to be lightweight and mobile-friendly, and work on Chrome and Safari for iOS and Android.

What file formats are supported?

Depending on the tool: MP4, MP3, WAV, OGG, FLAC for audio; PNG, JPG, WEBP, HEIC, GIF for images; PDF for document tools; MP4, WebM, MOV for video. Each tool page lists its supported formats.
